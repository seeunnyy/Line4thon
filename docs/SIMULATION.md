# SIMULATION.md

## 1. 목적과 범위
- 이벤트 시뮬레이션은 **룰 기반 계산**이다. LLM은 계산하지 않는다 (docs/LLM.md 참고).
- 결과는 단정이 아니라 "예보"다. 화면 문구에는 항상 "약", "~쯤", 범위 표현을 쓴다 (예: "약 0.2kg", "1~2kg 정도로 예상돼요"). 예외: 하루 권장 섭취 칼로리(TDEE)는 사용자 입력으로 계산한 개인 기준값이라 "약"을 붙이지 않는다(6장).
- 여기 없는 숫자·공식·기준은 코드에 임의로 추가하지 않는다. 필요하면 이 문서를 먼저 갱신한다.

## 3. 구성 요소 정의

### 3-0. 개인 기준선 (평소 날)

```
BMR  = 10×체중(kg) + 6.25×키(cm) − 5×나이(세) + 성별보정(남성 +5 / 여성 −161)
TDEE = BMR × 활동계수      ← 화면 이름: "하루 권장 섭취 칼로리"
```

- **평소 날**: 이벤트가 없는 날은 섭취 ≈ TDEE, 즉 초과 kcal = 0이다. 실제 지방 변화 0, 표시체중 변화 0(평평한 선).
- 시뮬레이션 입력인 **초과 kcal은 언제나 "TDEE 대비 초과분"**이다. 직접 입력값과 프리셋(650 / 1,000 / 2,000) 모두 같은 의미다.
- TDEE는 "평소"의 기준을 정할 뿐, 4장 이벤트 곡선 공식에는 들어가지 않는다.
- 키·체중·나이·성별·활동량은 모두 선택 입력이다. 하나라도 비어 있으면 TDEE는 **미계산**으로 두고(대체값을 넣지 않는다), 시뮬레이션은 초과 kcal만으로 그대로 동작한다.
- 섭취가 TDEE보다 적은 날(결손)은 이번 모델에서 다루지 않는다.

### 3-1. 표시체중 구성 요소

표시체중_변화량(t) = 실제지방_변화량 + 장내용물_잔량(t) + 글리코겐나트륨_잔량(t)

- **실제 지방 변화**: 초과 섭취 kcal이 실제로 체지방으로 남는 양. 이벤트가 끝나도 사라지지 않는 영구적 변화(작지만 누적됨). 시간에 따라 변하지 않는 수평선으로 표시.
- **글리코겐·수분 + 나트륨 세포외액 (하나의 곡선으로 통합)**: 이벤트로 인한 탄수화물 과다 섭취 시 글리코겐이 여분의 물을 동반 저장하고, 나트륨 과다 섭취 시 세포외액이 늘어나는 두 메커니즘을 하나의 "체내 수분 저류" 곡선으로 합쳐서 다룬다. 48~72시간(대표 60시간)에 걸쳐 선형 감소해 소실.
- **장내용물**: 아직 소화되지 않은 음식물의 무게. 24~72시간(대표 48시간)에 걸쳐 선형 감소해 소실.

## 4. 계산 절차

**입력**: `events` 배열. 이벤트마다 `{ 초과 kcal(TDEE 대비), 시작 시각, 끝 시각 }`. 초과 kcal은 직접 입력 또는 강도 프리셋 선택. 이벤트가 없으면 빈 배열(= 평소 날, 3-0).

### 4-A. 이벤트 1건 계산 (이벤트 i마다 따로)

1. **초과 kcal 결정**
   - 직접 입력 모드: 사용자가 입력한 값을 그대로 사용. 입력값은 그날 총 섭취량이 아니라 **평소보다 더 먹을 칼로리(초과분)**다. 화면 라벨도 "평소보다 더 먹을 칼로리"로 쓴다
   - 프리셋 모드: 가볍게=650 / 보통=1,000 / 많이=2,000kcal [가정] 사용. 이벤트 유형(회식/여행/명절/시험기간)은 프리셋 기본 선택값을 미리 채우는 용도로만 쓴다(예: "명절" 선택 시 "많이" 기본 선택, 사용자가 직접 조정 가능). 계산식 자체에는 이벤트 유형이 관여하지 않는다.
2. **강도 비율 계산**: `ratio = clamp((초과kcal - 650) / (2000 - 650), 0, 1)` [가정: 650/2,000을 보간 앵커로 사용, 범위를 벗어나면 low/high로 clamp]
3. **각 성분 시작값(t=0) 계산**: `low + ratio × (high - low)`
   - 글리코겐·수분·나트륨 시작값 = (글리코겐+수분 1.5~2kg 구간 보간값) + (나트륨 0~2L≈0~2kg 구간 보간값)
   - 장내용물 시작값 = 500~1,000g 구간 보간값
4. **실제지방_변화량** = 초과kcal ÷ 7,700 (고정값, 시간에 따라 변하지 않음)
5. **시간축 t (0~72시간)에서 표시체중 곡선 계산**
   - `장내용물_잔량(t) = 장내용물_시작값 × max(0, 1 - t/48)`
   - `글리코겐나트륨_잔량(t) = 글리코겐나트륨_시작값 × max(0, 1 - t/60)`
   - `표시체중_변화량(t) = 실제지방_변화량 + 장내용물_잔량(t) + 글리코겐나트륨_잔량(t)`
   - `실제지방선(t) = 실제지방_변화량` (항상 일정한 수평선)
6. **여러 날 이어지는 이벤트(여행 등)**: 전체 기간을 "총 초과 kcal" 1건으로 묶어 단일 이벤트로 계산한다. 일별로 분해해 누적하지 않는다. (4-B의 "여러 이벤트"는 서로 다른 이벤트 여러 건을 말한다.)

### 4-B. 여러 이벤트 합산

이벤트 i마다 4-A의 2~4단계로 시작값을 구하되, 글리코겐·수분과 나트륨은 합산 상한 때문에 **따로 들고 있다가** 합친다.

```
T_i = 이벤트 i가 끝난 시각 (여러 날 이벤트는 마지막 날이 끝난 시각)
t_i = t − T_i                       (t_i < 0이면 이벤트 i는 아직 기여하지 않는다)

감쇠48(t_i) = max(0, 1 − t_i/48),  감쇠60(t_i) = max(0, 1 − t_i/60)   (t_i ≥ 0일 때)

장내용물_합(t)   = Σ_i 장내용물_시작값_i × 감쇠48(t_i)
글리코겐_합(t)   = min(2kg, Σ_i 글리코겐수분_시작값_i × 감쇠60(t_i))
나트륨_합(t)     = min(2kg, Σ_i 나트륨_시작값_i × 감쇠60(t_i))
실제지방_합(t)   = Σ_{t_i ≥ 0} 실제지방_i

표시체중_변화량(t) = 실제지방_합(t) + 장내용물_합(t) + 글리코겐_합(t) + 나트륨_합(t)
실제지방선(t)      = 실제지방_합(t)   (이벤트가 끝날 때마다 한 칸씩 오르는 계단형)
```

- **실제 지방·장내용물은 그대로 합산**한다. 지방은 영구 변화라 쌓이고, 장내용물은 실제로 먹은 음식의 무게라 이벤트마다 더해진다.
- **글리코겐·수분과 나트륨 세포외액은 합산하되 상한을 둔다** (2장 합산 상한, 각 2kg).
  - 글리코겐: 저장 용량에 생리적 상한이 있다(원문 최대 저장 400~500g). 이미 채워진 상태에서 다음 이벤트가 오면 더 쌓이지 않고, 남는 탄수화물은 산화되거나 지방 합성으로 간다(지방 쪽은 초과kcal ÷ 7,700에 이미 포함).
  - 나트륨: 고나트륨이 이어지면 약 하루 뒤 신장 배설이 섭취를 따라잡아 세포외액이 새 평형에서 멈춘다. 연달은 이벤트로 끝없이 늘지 않는다.
  - 이벤트 1건이면 각 성분이 이미 상한 이하(글리코겐 1.5~2kg, 나트륨 0~2kg)라서 4-A 결과와 똑같다.
- 두 성분은 같은 60h 감쇠를 쓰므로 화면에서는 지금처럼 **하나의 "체내 수분 저류" 곡선**(글리코겐_합 + 나트륨_합)으로 보여준다.
- 이벤트 기간이 서로 겹쳐도(예: 여행 중 회식) 따로 등록된 이벤트면 각자 계산해 위 식으로 합친다.
- 시간축: 첫 이벤트가 끝난 시각부터 마지막 이벤트가 끝나고 72시간 뒤까지.

## 5. 검증 예시 (단위 테스트 기준)

회식 한 번, 초과 +1,500kcal 과식 가정
- 실제 지방 변화 = 1,500 ÷ 7,700 ≈ **0.19kg** (원문 "약 0.2kg"과 일치)
- 다음 날(t≈24h) 체중계에 찍히는 **+1~2kg**은 대부분 글리코겐·수분·나트륨·장내용물이고, 실제로 영구히 남는 지방은 0.19kg뿐
- 48~72시간에 걸쳐 표시체중이 실제 체중선(0.19kg 부근)으로 수렴한다

이벤트 없음 (평소 날)
- `events = []` → 모든 t에서 표시체중 변화 0, 실제지방선 0

겹치는 두 이벤트 (+1,500kcal 두 건, 24시간 간격)
- 이벤트마다 ratio = (1,500 − 650) ÷ 1,350 ≈ 0.63 → 글리코겐·수분 시작값 ≈ 1.81kg, 나트륨 시작값 ≈ 1.26kg
- 두 번째 이벤트 직후: 글리코겐 합 ≈ 1.09 + 1.81 = 2.90kg → 상한 **2kg**, 나트륨 합 ≈ 0.76 + 1.26 = 2.02kg → 상한 **2kg**
- 실제지방선: 첫 이벤트 뒤 ≈ 0.19kg → 두 번째 이벤트 뒤 ≈ **0.39kg** (계단형)

TDEE (계산 확인용)
- 여성, 30세, 165cm, 60kg, 좌식 → BMR = 600 + 1,031.25 − 150 − 161 = 1,320.25 → TDEE = 1,320.25 × 1.2 = 1,584.3 → 표시 **1,584kcal**

## 6. 표시 규칙

- 체중은 원값이 아니라 **7일 이동평균**으로 표시한다 [확정]
- **BMI는 근육량을 반영하지 못하므로 단일 지표로 쓰지 않는다** [확정]
- **이중 그래프(표시체중 vs 실제 지방)와 이동평균이 메인 지표**다 [확정]
- 결과는 "예보"이므로 화면 문구에 "약", "~쯤", 범위 표현을 사용한다 (예: "약 0.2kg", "1~2kg 정도로 예상돼요")
- **TDEE 표시**: 계산값이 소수일 때만 정수로 반올림한다(정수면 그대로). "약"을 붙이지 않는다. 예: "하루 권장 섭취 칼로리 1,584kcal". 미계산이면 숫자를 보여주지 않는다.
- **온보딩 TDEE 결과**: 몸 정보 5개(성별·나이·키·체중·활동량)가 모두 채워진 경우에만, 아바타 설정으로 넘어가기 전에 한 번 보여준다(같은 화면의 두 번째 상태). 하나라도 비었거나 "나중에 할게요"를 누르면 결과 없이 넘어간다. 닉네임이 있으면 "OOO님의 하루 권장 섭취 칼로리"로 부른다.
- **프리셋 개인화 비교**: 프리셋 kcal은 고정값 그대로 두고, 선택된 프리셋 아래에 한 줄로 "하루 권장량보다 약 O% 더"를 보여준다.
  - `비교율 = 초과kcal ÷ TDEE × 100`, **10% 단위로 반올림**, 예보 값이므로 "약"을 붙인다 [가정, 승인됨]
  - 예: TDEE 1,584kcal → 가볍게 650 = 41% → "약 40% 더", 보통 1,000 = 63% → "약 60% 더", 많이 2,000 = 126% → "약 130% 더"
  - TDEE가 미계산이면 비교 문구를 보여주지 않는다. 계산식(4장)에는 영향이 없고 설명에만 쓴다.
  - "권장량의 O%"라고 쓰지 않는다. 하루 전체를 그만큼만 먹는다는 뜻으로 잘못 읽힌다.
