# PRD.md

## Problem
다이어트가 무너지는 건 의지 부족이 아니라, 회식·여행·명절처럼 예정되어 있었지만 설계되지 않은 이벤트, 그리고 일탈을 전체 실패로 오인하는 인지왜곡 때문이다.

## Target User
N차 재도전자 — 다이어트를 3회 이상 시도했다가 중단한 경험이 있고, 기존 다이어트 앱에 대한 신뢰가 낮은 20~30대

## Core Value
예정된 이벤트를 미리 시뮬레이션해 무너짐 자체를 방지하고, 무너지더라도 계획된 복귀로 이어준다.

## Core Features
- 이벤트 시뮬레이터 (표시체중 vs 실제지방 이중 그래프)
- AI 재개 코치 (준비도 체크인 → 단계적 복귀)
- 일탈 리프레이밍 개입
- 재도전 경험치화
- 동반자 캐릭터 (행동 기반 반응)
- 날씨 UI

## Non-goals
- 결제/구독 기능
- 복잡한 소셜 인증
- 실시간 협업
- 대용량 파일 업로드
- InBody·웨어러블 등 다중 외부 연동 (2단계 이후)

## Success Criteria
- 해커톤 데모 시연 가능한 수준의 동작하는 MVP
- 이벤트 등록 → 시뮬레이션 → 재개 체크인까지 핵심 플로우 1개 완주
