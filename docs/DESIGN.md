# DESIGN.md

## Design Goal
반복되는 다이어트 실패에 지친 사용자에게 부담을 주지 않는, 차분하고 신뢰감 있는 웹 앱.

## Visual Tone
- Calm (경쟁·보상 요소 없이 잔잔하게)
- Minimal
- Easy to scan
- Card-based when useful
- "날씨예보" 은유 — 체중 변화를 날씨처럼 자연스러운 변동으로 표현

## Main Screens
- Landing Page
- App Page
  - 이벤트 등록
  - 시뮬레이션 결과 (표시체중 vs 실제지방 이중 그래프)
  - 재개 체크인

## UI Rules
- Use clear button text.
- Use labels for inputs.
- Use semantic headings.
- Avoid icon-only actions.
- Avoid random design changes.
- 체중/신체 변화를 외형 이미지로 직접 보여주지 않는다 (동반자 캐릭터는 표정·소지품으로만 반응)
